## 导入

把 ZIP 或 JSON 放到设备的下载目录，打开「我的」→「选择 ZIP / JSON 备份恢复」，选择文件并核对确认页的「词汇 120 · 笔记 8 · 图片 0」，再确认恢复。

恢复会覆盖当前学习数据，请先导出原数据；服务配置和密钥保留。本次测试已在 Pixel_9a 模拟器通过真实文件选择器导入，并保留模拟数据。模拟器的「回到上次恢复前」可恢复导入前数据。
