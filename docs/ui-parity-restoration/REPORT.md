同一 Pixel 9a 模拟器、1080×2424、420 dpi、浅色及标准字号；原版与改动前来自[上一轮实拍](../ui-parity-2026-10-27/REPORT.md)，改动后使用同一词条和标签 fixture。三列依次是原版、改动前、改动后，截图仅等比缩放和加标题。模型设置三列滚动偏移不同，主要用于比较表单区域；原始图及可访问性树在 `after/`。

- [笔记页对比](compare/notebooks.png)：分类顺序、同排筛选、首条释义摘要与编辑图标更接近；原版删除图标及部分间距、按钮样式仍不同。
- [设置首屏对比](compare/settings.png)：高级设置入口与服务说明的层次更接近；TokenDance 账户区仍未迁移。
- [模型配置对比](compare/model-editor.png)：预设供应商改为平铺，模型、视觉提示、密钥和测试操作重新排列；Java 仍有额外的模型刷新、手动参数和最高推理档位。
- [供应商平铺和模型配置顶部](after/model-editor.png)；[切换 DeepSeek 后](after/settings-deepseek.png)；[批量管理模式](after/notebooks-selection.png)。

## 功能与验证

笔记保留分类管理、标签筛选、批量操作、编辑和多笔记共享引用；摘要仅显示首条可见释义，完整内容仍在详情中。服务配置保留供应商独立加密密钥、手动配置、模型发现、能力信息、测试和取消；切换时对未保存的草稿进行确认。TokenDance 专属登录授权、充值和调用记录尚未接入，页面明确提示，不提供虚假的操作按钮。

构建：离线 `testDebugUnitTest lintDebug assembleDebug` 成功，101 项 JVM 测试通过；模拟器通过 10 组冒烟、7 组功能、2 组模型配置检查。另用真实界面切换 TokenDance/DeepSeek，并拍摄笔记批量管理界面。本轮未调用在线模型 API，也未测试真机、深色模式或大字号。

截图期间临时保存并恢复模拟器的私有词库及供应商配置，恢复前后各自 SHA-256 一致；原 Expo 工作区保持干净。
