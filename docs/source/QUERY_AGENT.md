# 统一查询与 AI 会话（v1.3）

沿用 OpenAI 兼容接口和轻量 TypeScript 控制器，无独立后端、LangChain 或新增运行时依赖。会话创建时间、使用时间由本地存储服务维护，不由模型生成。

## 页面与查询边界

查询记录首页保留三个模式的固定高度查询卡片，其下是保存会话和临时会话。图片 contain 预览，图文、图片、文本模式的卡片高度一致；大字号增加统一高度，卡片内部和首页允许滚动。

查询信息使用根 Stack 的 `query/[id]` 路由，不显示首页顶栏、查询区和底部 Tab。AI 助手固定为 `assistant/[id]` 全屏页面，没有半屏和全屏切换。路由只传 ID，共享 `ConversationProvider` 持有控制器、查询草稿与会话存储。

明确词条优先匹配本地词库，其他输入由模型结合图片、百分比框选、原问题和上下文判断。返回 `clarify`、`confirm_lookup`、`answer`、`request_input` 或初次/已确认的 `lookup_result`。格式最多修复一次，总请求超时 45 秒，鉴权/网络错误不做格式重试。

助手中的新查词卡片先返回首页，将目标、来源和要求放入草稿，再点击「确认查询」执行；成功进入独立结果页，助手不再占据屏幕。确认绑定提案 ID、消息和版本，控制器拒绝在结果页或助手页执行。首页编辑新草稿不修改已保存会话；重新提交创建新查询。

## 追问、保存与命名

模型 JSON 可附 `follow_up_questions`，校验有效短文本、去重，最多三个，无有效候选就不显示。点击只填入输入框，发送仍需用户操作。移除固定三项。

全屏助手右上角「保存会话」可手动命名或采用 AI 候选名称。已保存会话可改名、继续对话；保存不保存词汇笔记，保存词汇也不自动保存会话。

新建临时会话空白时不占名额，首次发送后落盘；最多五个，按最近使用时间淘汰。临时会话收到回复后异步请求 AI 标题，失败保留回退标题，普通答疑不等待命名。AI 名称最多 40 字，命名请求只携带文字摘要，不重复上传图片，超时 25 秒。手动名称优先，标题版本和取消信号阻止迟到回写。

保存列表按名称子串搜索（NFKC、忽略大小写），可选择创建日期或最近使用日期的起止范围，两种条件 AND 组合。结束日包含全天。列表筛选和后台改名不改变使用时间；打开和交流更新使用时间。

## 历史、滚动与一致性

最近十条查询与五条临时会话、无限条主动保存会话分别管理。查询历史保留紧凑索引，完整图片、消息、待确认卡片保存在会话集合。删除最近查询不删除同 ID 的主动保存会话，清空历史不清空保存/临时会话。

历史消息使用倒序虚拟列表，初始位置为最新消息，向上阅读暂停跟随。内容尺寸变化和新回复不会强制回底部，圆形悬浮按钮位于输入框上方，点击恢复跟随并清除未读计数。按需渲染历史，普通答疑完整校验后展示，不增量流式显示。

查询和会话写入成对串行；删除标记、请求版本及恢复代次阻止迟到数据复活。恢复备份前取消查询/命名并等待旧写入完成，恢复后等待会话权威重载再解除加载状态。打开历史不会重新生成结果或重复触发自动入库。自动入库只消费一次本次完成事件。

## 全量词汇与笔记显示

单词、短语始终记录全部已获得的释义、中英文、例句、来源、图片和备注。查询勾选转为目标笔记的显示配置，原词汇不做删减。词汇详情「按笔记配置显示内容」可分别调整各笔记，同一词汇在不同笔记中显示不同内容；可切换查看词库完整内容。

备注/批注归属于 `meaning_id`，同一释义允许多条。保存时可选择备注绑定的释义，详情可继续添加与删除单条备注。不同词性或冲突的释义应保留独立记录，合并时保留既有批注与图片。

## 迁移与验证

ZIP 格式 2.2 纳入会话、时间、名称、显示配置和共享图片，兼容 2.1/2.0 ZIP 及 1.0/1.1 JSON、旧四键恢复日志。旧历史最近使用时间取有效最后消息与创建时间的最大值。API Key 不进入会话和备份。

自动化：`npm test`、`npm run lint`、`npx tsc --noEmit`、`git diff --check`；Android JS 生产导出：`npx expo export --platform android --output-dir dist/v1.3-android`。

需另做原生与真实模型验收：图文澄清后返回确认、独立结果与返回、固定全屏助手及键盘、200 条含 Markdown/图片历史的进入/上翻/回底部、手动与 AI 名称保存、日期检索、第六条临时淘汰、断网和恢复备份。Node 状态测试不能替代这些体验验收。
