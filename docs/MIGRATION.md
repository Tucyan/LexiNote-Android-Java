# Android 原生迁移记录

迁移日期：2026-10-26（Asia/Singapore）。原项目基线：d465b969b76f9baaba3d098fb89342916e7efce9，原分支 codex/conversation-pages。迁移仓库独立初始化，分支 codex/android-native-java，无共享 Git 元数据或 origin。

## 架构决策

主要程序采用 Java 17 和 Android framework View。只引入 AndroidX ExifInterface 处理图片方向，不依赖 Expo、React Native、WebView 页面或 JavaScript bundle。AGP 的构建工具依赖不等于应用使用 Kotlin 编写。

第一版使用 AtomicFile JSON 文档保存本地实体和引用，方便保留旧备份未知字段并完成可靠导入。用户数据量超过本版受控文本容量会明确拒绝写入；后续扩展大型词库应迁移 SQLite/Room 并流式处理大备份。

保留 Vocabulary/Meaning/Annotation/Notebook 原字段、词汇共享实体、每笔记独立显示、查询历史快照。旧全局根计算索引在加载时重建；缺失的系统根自动补齐；旧式仅保留例句或批注的部分释义也可以恢复。新记录仍要求有效中文或英文定义。

API Key 与供应商连接独立存放，使用 Keystore AES/GCM；JSON/ZIP 备份脱敏，不覆盖本机连接。系统云备份/设备自动迁移均排除私有文件和密钥配置，数据迁移通过显式文件备份。

## 备份协议与来源文档

`docs/source/PRD.md` 和 `QUERY_AGENT.md` 是原仓库原样保留的设计文档。历史 PRD 的 ZIP 2.1 描述与 QUERY_AGENT 的 2.2 存在版本差异；本次实现以原 `backupFormat.ts` 的 2.2 编码与 2.0–2.2 解码为准，没有修改历史文档原文。
